# Security Policy

We take the security of this project seriously. Thank you for helping to keep it safe.

## Supported Versions

This project is a single static HTML application. The "version" being maintained is the
`main` branch.

| Version | Supported |
|---------|-----------|
| `main`  | ✅ Yes    |

## Reporting a Vulnerability

**Please do not open a public issue for a security vulnerability.** Report it privately
instead.

You can report a vulnerability using **GitHub's private vulnerability reporting** feature:

1. Open the repository on GitHub.
2. Go to **Security → Security advisories → Report a vulnerability**.
3. Follow the prompts to submit a private report.

Alternatively, contact the maintainer privately through GitHub.

### What to include

- A clear description of the issue and its impact.
- Steps to reproduce (including a minimal example, if possible).
- Any affected files/areas.
- Your suggested fix, if you have one.

### What to expect

- We will acknowledge receipt within a reasonable timeframe.
- We will keep you informed of progress.
- We request that you not disclose the issue publicly until a fix has been released and
  announced.

---

## Scope

Since this project is a static, client-side-only web page served over the public internet,
reports related to the following are especially welcome:

- Any user-supplied input that leads to unexpected behavior.
- Script injection or XSS via the character generator or game scoreboard.
- Security issues that could affect a visitor while the page is hosted.

Client-side code is executed in each user's own browser; the project itself does not store
or transmit personal data to a server.

Thank you for helping keep Teja Game Hub secure. 💜
